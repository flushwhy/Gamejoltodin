Quick start

From the repository root.

1. Install prerequisites

Install the Odin compiler and libcurl development files.

2. Build the library

# Windows
build.bat

# Linux / macOS
chmod +x build.sh
./build.sh

3. Initialize a session in Odin

import "core:fmt"
import "gamejolt"

main :: proc() {
    session := gamejolt.gj_init("YOUR_GAME_ID", "YOUR_PRIVATE_KEY")
    defer gamejolt.gj_destroy(&session)

    user, err := gamejolt.gj_login(&session, "username", "token")
    if err == .None {
        defer gamejolt.gj_user_delete(&user)
        fmt.printf("Logged in: %s (ID: %d)\n", user.username, user.id)
    } else {
        fmt.printfln("Login failed: %v", err)
    }
}

Replace placeholders with your own credentials. Keep the private key out of public client-side distributions where possible.

API areas

One implementation, two interfaces.

Player & sessions

Authenticate a player, check login state, and open, ping, or close a play session.

Game progression

Fetch and unlock trophies, submit player or guest scores, and read leaderboard tables.

Cloud data

Read, write, remove, and list keys in user-scoped or global data stores.

Errors & buffers

C calls return status codes and use caller-owned buffers. Check gamejolt.h for exact signatures and capacity rules.
